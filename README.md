# Desloca EAU

Webmap participativo dos deslocamentos de estudantes de Arquitetura e Urbanismo da UFF até a Escola de Arquitetura e Urbanismo (Praia Vermelha), com dashboard de tempo de aula, estágio, deslocamento e sono possível.

- Site estático em `docs/` (GitHub Pages).
- Banco: Supabase. Crie a tabela com `supabase/schema.sql` e preencha `docs/config.js`.
